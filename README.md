# 🚑 AED Management System - Frontend

The web dashboard interface for the global Automated External Defibrillator (AED) monitoring system. It provides operators with real-time visibility over deployed AED units, interactive geographical maps, self-test health metrics, and automated alerts for device maintenance.

## 🌟 Key Features
* **Interactive Dashboard:** Live status updates and visual metrics for all monitored AED devices.
* **Global Map View:** Real-time geolocation tracking for units deployed across the world.
* **Self-Test Monitoring:** Detailed logs and status indicators for battery, pads, and system checks.
* **Alert & Incident Center:** Immediate notifications for critical failures or required maintenance.
* **Operator Controls:** Management tools for viewing device history and handling system configurations.

## 🛠 Tech Stack
* **Core:** React.js
* **Build Tool / Bundler:** Create React App
* **State Management:** React Context
* **UI Components & Styling:** Material UI
* **HTTP Client:** Axios
* **API Integration:** Connects directly with the .NET 8 Backend API
